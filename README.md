# Карточки — локальный аналог Quizlet

Локальный сайт для заучивания слов: **модули → темы → карточки**, массовый импорт сплошным текстом,
четыре режима обучения и система Лейтнера. Работает на вашем компьютере, без регистрации и облака.
Интерфейс на русском, шрифт Inter (лежит в проекте, интернет для него не нужен).

## Запуск

```bash
npm install
npm start
```

Откройте http://localhost:3000. Нужен Node.js 22.13 или новее (проверено на 22; ничего компилировать не нужно, SQLite встроен в Node.js).
Сервер слушает только `127.0.0.1`, то есть доступен лишь с этого компьютера.

Демо-данные (модуль с двумя темами): `npm run seed` (добавляет их, только если база пуста).
Тесты: `npm test`.

Данные хранятся в `data/app.db` (SQLite), картинки — в `data/images/`. Чтобы сделать бэкап, скопируйте папку `data/`.

## Как пользоваться

1. **+ Новый модуль** — задайте название и языки (термины / определения: английский или русский).
2. В модуле создайте **тему**.
3. В теме нажмите **Импорт текстом** и вставьте список:
   ```
   apple - яблоко
   to run - бегать
   beautiful - красивый
   ```
   - Разделитель термина и определения: тире, двоеточие, Tab, точка с запятой или свой символ.
   - Карточки разделены новой строкой или пустой строкой (во втором случае определение может занимать несколько строк).
   - Перед сохранением виден предпросмотр: строки без разделителя подсвечены красным, дубликаты (в модуле или в самом списке) — жёлтым и по умолчанию не добавляются. Любую строку можно поправить.
4. **Учить** (в теме, модуле или на главной) — выберите режим, направление и набор карточек.

## Режимы

| Режим | Как работает |
|---|---|
| Флеш-карточки | Пробел — перевернуть, → «Знаю», ← «Не знаю», S — озвучить. «Не знаю» возвращает карточку в конец очереди. |
| Тест | 4 варианта (неверные берутся из других карточек модуля), клавиши 1–4. |
| Ввод ответа | Регистр, ё/е и лишние пробелы не важны. Несколько ответов через `/`, `,` или `;`. Опечатка в 1 букву для слов длиннее 5 символов засчитывается («почти верно»). Кнопка «Я был прав» исправляет вердикт вручную. |
| Сопоставление | На время, раунды по 6 пар. Рекорд хранится в браузере. |

Направление: термин → определение, определение → термин или вперемешку.

## Система Лейтнера

Пять коробок с интервалами **1, 2, 4, 8, 16 дней**. Новая карточка попадает в коробку 1.
Верный ответ поднимает карточку на коробку выше, неверный возвращает в коробку 1.
Верный ответ в коробке 5 помечает карточку как выученную. Ответ учитывается один раз за сессию, по первой попытке.
Режим «Повторение на сегодня» берёт только карточки, срок которых наступил. Число таких карточек видно на главной и в боковой панели.
«Повторить ошибки» в конце сессии — это тренировка, она коробки не меняет.

## Транскрипция и озвучка

- **Озвучка** — встроенный синтез речи браузера (кнопка 🔊, офлайн). Голос зависит от установленных в системе голосов en-US и ru-RU.
- **Транскрипция IPA** для английских слов подтягивается из бесплатного [Free Dictionary API](https://dictionaryapi.dev) (нужен интернет), кешируется в базе и редактируется вручную. Для фраз и редких слов её в словаре может не быть.

## Ассоциативные картинки (ИИ)

Генерируются по запросу (кнопка 🖼 у карточки, «Сгенерировать картинки» в теме или галочка при импорте), сохраняются в `data/images/`
и дальше показываются из кеша без интернета. Своё изображение можно загрузить вручную.

Провайдер задаётся в файле `.env` (скопируйте `.env.example`):

| `IMAGE_PROVIDER` | Что нужно |
|---|---|
| `pollinations` (по умолчанию) | Ключ не нужен. Качество и доступность сервиса не гарантируются; при необходимости задайте `POLLINATIONS_TOKEN`. |
| `openai` | `OPENAI_API_KEY`, модель — `OPENAI_IMAGE_MODEL` (по умолчанию `gpt-image-1`). Платно. |

Чтобы добавить другого провайдера, добавьте функцию в объект `providers` в `server/enrich.js`: она получает текстовый запрос и возвращает `{ buffer, ext }`.
Если интернета или ключа нет, приложение покажет сообщение об ошибке и продолжит работать.

## Экспорт и импорт

- **Экспорт JSON** (модуль целиком, вместе с картинками и прогрессом) и **Импорт** этого файла кнопкой в боковой панели.
- **Экспорт текст** (модуль или тема) в том же формате, что и массовый импорт. В файле модуля темы отмечены строками `## Тема`, такой файл тоже можно импортировать. Переводы строк в определениях при текстовом экспорте заменяются пробелами.

## Решения, принятые по умолчанию

- Состояние «выучена» у карточки сбрасывается после любой ошибки.
- Новые карточки считаются «к повторению» сразу (дата повторения — день создания).
- Дни считаются по локальному времени компьютера.
- Если термин содержит ` - `, при импорте с разделителем «тире» он разобьётся по первому вхождению; в таком случае выберите другой разделитель.
