# Карточки — аналог Quizlet для планшета и компьютера

Приложение для заучивания слов флеш-карточками: **модули → темы → карточки**, массовый импорт сплошным текстом,
четыре режима обучения и система Лейтнера. Интерфейс на русском, шрифт Inter.

**Сервер не нужен.** Приложение целиком работает в браузере, а данные хранятся на самом устройстве (IndexedDB).
После первой загрузки оно работает без интернета и без Wi-Fi. Интернет нужен только для необязательных функций:
транскрипции IPA и картинок от ИИ.

## Установка на планшет (один раз, нужен интернет)

Сайт публикуется бесплатно через GitHub Pages прямо из этого репозитория.

**1. Включите GitHub Pages** (делается один раз в браузере на компьютере):
1. Откройте репозиторий на github.com → **Settings** → слева **Pages**.
2. В блоке *Build and deployment* в поле **Source** выберите **Deploy from a branch**.
3. В поле **Branch** выберите ветку `claude/quizlet-analogue-prompt-dhhqms` (позже, когда ветку объединят с `main`, выберите `main`), а рядом папку **/docs**. Нажмите **Save**.
4. Через 1–2 минуты вверху страницы появится адрес вида `https://amberbaybaythv-cell.github.io/Quizlet/`.

**2. Откройте адрес на планшете** в Chrome (Android) или Safari (iPad) и добавьте на главный экран:
- Android / Chrome: меню ⋮ → **«Установить приложение»** или **«Добавить на главный экран»**.
- iPad / Safari: кнопка «Поделиться» → **«На экран „Домой“»**.

После этого приложение открывается с иконки, как обычное, и работает без интернета.
Добавление на главный экран ещё и защищает данные: система реже удаляет память установленных приложений.

## Запуск на компьютере (по желанию)

Нужен Node.js 18 или новее. Зависимости устанавливать не нужно:

```bash
npm start      # http://localhost:3000
```

Данные хранятся в браузере, в котором вы открыли сайт, поэтому на компьютере и на планшете они **разные**.

## Перенос данных между устройствами

- **Настройки → Скачать копию всех модулей** сохраняет один JSON-файл (карточки, картинки, транскрипции и прогресс по коробкам).
- На другом устройстве нажмите **Импорт** в боковой панели и выберите файл. Импорт всегда создаёт новые модули и ничего не перезаписывает.
- Одиночный модуль можно выгрузить в настройках модуля (⚙️ на странице модуля): «Экспорт JSON» и «Экспорт текст». Там же добавление темы и удаление модуля.
- Файл экспорта старой серверной версии приложения тоже импортируется.

Резервную копию стоит делать время от времени: если очистить данные сайта в настройках браузера, карточки пропадут.

## Оформление

В **⚙️ Настройки → Оформление** можно выбрать акцентный цвет (кнопки, ссылки, графики): фиолетовый (по умолчанию), песочный `#EED9C4`, «Старое дерево» `#9E7655` или «Эспрессо» `#644736`.
Светлая и тёмная тема переключаются кнопкой 🌓 в боковой панели. Блоки статистики на главной, странице модуля и странице темы
сворачиваются стрелкой справа от заголовка (по умолчанию общий блок «Статистика» закрыт), выбор запоминается.
Чтобы добавить ещё один оттенок, дополните список `ACCENTS` в `docs/js/app.js` и блок `:root[data-accent="…"]` в `docs/css/style.css`.

## Как пользоваться

1. **+ Новый модуль** — задайте название и языки (термины / определения: английский или русский).
2. В модуле создайте **тему**.
3. В теме нажмите **Импорт текстом** и вставьте список:
   ```
   apple - яблоко
   to run - бегать
   beautiful - красивый
   ```
   - Разделитель термина и определения: тире, двоеточие, Tab, точка с запятой или свой символ.
   - Карточки разделены новой строкой или пустой строкой (во втором случае определение может занимать несколько строк).
   - Перед сохранением виден предпросмотр: строки без разделителя подсвечены красным, дубликаты (в модуле или в самом списке) — жёлтым и по умолчанию не добавляются. Любую строку можно поправить.
4. **Учить** (в теме, модуле или на главной) — выберите режим, направление и набор карточек.

## Блоки внутри темы

Карточки темы можно разделить на **блоки** (например, «Блок 1», «Блок 2» или «Глаголы», «Существительные»). Блоки создаются, переименовываются и удаляются
**только на странице открытой темы**: на главной, в модуле и в боковой панели их не меняют.

- Над таблицей карточек лежат переключатели «Все», «Без блока» и сами блоки. Стрелка **‹ / ›** рядом с «Все» сворачивает и разворачивает всю эту строку (вместе с «+ Блок» и «Разделить на блоки…»), выбор запоминается. Кнопка **+ Блок** создаёт блок, **Разделить на блоки…** раскладывает карточки без блока по группам одинакового размера.
- Чтобы перенести карточки, отметьте их галочками: появится панель «Переместить в…» (можно создать новый блок прямо из неё). «Без блока» убирает карточки из блока.
- Выбранный блок можно **учить отдельно** (кнопка «Учить блок» или выбор «Что учить» в окне запуска). Новая карточка, добавленная при открытом блоке, попадает в него.
- Удаление блока не удаляет карточки: они остаются в теме без блока.
- В импорте текстом строка `### Название блока` начинает новый блок, а в окне импорта можно выбрать блок для всех карточек. Текстовый и JSON-экспорт сохраняют блоки.
- **Статистика по всем блокам** показана в разделе «Статистика темы» → «По блокам»: для каждого блока число карточек, процент выученных, карточки к повторению и разбивка по коробкам Лейтнера. Клик по названию блока открывает его карточки. Статистика темы, модуля и главной по-прежнему считается по всем карточкам.

## Режимы

| Режим | Как работает |
|---|---|
| Флеш-карточки | Пробел или касание — перевернуть, → «Знаю», ← «Не знаю», S — озвучить. «Не знаю» возвращает карточку в конец очереди. |
| Тест | 4 варианта (неверные берутся из других карточек модуля), клавиши 1–4. |
| Ввод ответа | Регистр, ё/е и лишние пробелы не важны. Несколько ответов через `/`, `,` или `;`. Опечатка в 1 букву для слов длиннее 5 символов засчитывается («почти верно»). Кнопка «Я был прав» исправляет вердикт вручную. |
| Сопоставление | На время, раунды по 6 пар. Рекорд хранится в браузере. |

## Система Лейтнера

Пять коробок с интервалами **1, 2, 4, 8, 16 дней**. Новая карточка попадает в коробку 1.
Верный ответ поднимает карточку на коробку выше, неверный возвращает в коробку 1.
Верный ответ в коробке 5 помечает карточку как выученную. Ответ учитывается один раз за сессию, по первой попытке.
**Каждый ответ сохраняется сразу**, поэтому из режима можно выйти в любой момент (кнопка «← Выйти»), прогресс не потеряется. Рядом с полосой прогресса показано «✓ Сохранено: N».
Режим «Повторение на сегодня» берёт только карточки, срок которых наступил.
«Повторить ошибки» в конце сессии — это тренировка, она коробки не меняет.

## Озвучка, транскрипция и картинки

- **Озвучка** — встроенный синтез речи устройства (кнопка 🔊, офлайн). Голос зависит от голосов en-US и ru-RU, установленных на планшете.
- **Транскрипция IPA** для английских слов подтягивается из бесплатного [Free Dictionary API](https://dictionaryapi.dev) (нужен интернет) и сохраняется на устройстве. Редактируется вручную. Для фраз и редких слов её в словаре может не быть.
- **Свои картинки.** В окне карточки (кнопка 🖼) картинку можно **вставить из буфера**: скопируйте её на сайте (правая кнопка → «Копировать изображение», на планшете долгое нажатие) и нажмите «Вставить из буфера» либо Ctrl+V. Также работают перетаскивание картинки и загрузка файла. Если сайт отдаёт только ссылку на картинку, а не саму картинку, браузер может запретить её скачать: тогда используйте «Копировать изображение».
- **Настоящие фото из Википедии и Wikimedia Commons** (без ключей, нужен интернет). В окне карточки блок «Найти фото…» показывает варианты, по нажатию выбранное фото сохраняется на устройстве вместе с автором, лицензией и ссылкой на источник. Кнопка «Найти фото (Wikimedia)» в теме подбирает фото сразу для всех карточек без картинки, то же можно включить галочкой при импорте. Если определение короткое («apple — яблоко»), поиск идёт по нему в Википедии на его языке, поэтому находится статья про фрукт, а не про компанию. Для абстрактных слов («анализ») результат может быть случайным, их лучше выбирать вручную.
- **Картинки от ИИ** (кнопка 🖼 у карточки, «Сгенерировать картинки» в теме или галочка при импорте) сохраняются в карточке в уменьшенном виде и дальше показываются без интернета.
  Своё изображение можно загрузить вручную.

Запросы к сервисам картинок идут прямо из браузера, поэтому нужен ключ. Откройте **⚙ Настройки** и выберите провайдера:

| Провайдер | Что нужно |
|---|---|
| Hugging Face (рекомендуется) | Бесплатный аккаунт на [huggingface.co](https://huggingface.co), токен на [странице токенов](https://huggingface.co/settings/tokens) (тип Fine-grained, право «Make calls to Inference Providers»). Модель FLUX.1-schnell. У бесплатного тарифа есть месячный лимит. |
| OpenAI | Ключ API, платно. |
| Pollinations | Без ключа часто отвечает ошибкой 402. |

Ключи хранятся только в браузере устройства. Они не попадают в репозиторий и не уходят никуда, кроме выбранного сервиса.
Если генерация подряд падает 3 раза, очередь останавливается и показывает причину.
В окне карточки запрос для ИИ можно отредактировать: для абстрактных слов лучше описать простой образ по-английски,
например `a magnifying glass over a chart, flat illustration`.

## Для разработчика

```bash
npm test             # тесты разбора текста, проверки ответов и системы Лейтнера
npm run build:sw     # обновить список файлов и версию офлайн-кеша (docs/sw.js) после изменения файлов в docs/
```

После любых правок в `docs/` запускайте `npm run build:sw`, иначе устройства получат старую версию из кеша (тест это проверяет).
Структура: `docs/` — само приложение (его публикует GitHub Pages), `docs/js/store.js` — хранилище на IndexedDB,
`server/index.js` — простой статический сервер для локального запуска.

## Решения, принятые по умолчанию

- Состояние «выучена» у карточки сбрасывается после любой ошибки.
- Новые карточки считаются «к повторению» сразу (дата повторения — день создания).
- Дни считаются по локальному времени устройства.
- Если термин содержит ` - `, при импорте с разделителем «тире» он разобьётся по первому вхождению; в таком случае выберите другой разделитель.
